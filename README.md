# Yiduo Qu’s homepage

Simple static academic homepage, hosted on GitHub Pages at https://yiduoqu.github.io/.

Edit `index.html` to update the biography, publications, experience, and education. Edit `style.css` to adjust the layout. Files in `assets/` contain the portrait and CV.

GitHub Pages publishes the root of the `main` branch. No build step or dependencies are needed.

Publication thumbnails: DiagGen uses the project video thumbnail linked from Guanxiong Chen’s homepage; Agentic Real2Sim uses his publication preview; RARM uses a cloth-folding frame from its project website. Each thumbnail links to its corresponding project.
